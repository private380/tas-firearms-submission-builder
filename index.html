Methodology

How these figures were collected

What was stored

For each recorded submission, the builder added anonymous aggregate counts for the selected position on each amendment and for selected predefined broader suggestions and closing statements.

What was not stored

The reporting dataset did not store names, email addresses, PDF files or free-text comments in the community-results aggregate.

When a result was counted

The result was recorded when a user selected Save submission as PDF. The builder attempted to prevent the same unchanged submission from being counted repeatedly on the same device.

Interpretation

This is evidence of the views expressed by people who used this independent tool. It should not be presented as a representative poll of Tasmania or as an official consultation outcome.

About this project

Independent submission-assistance project

This website is independent and is not operated by, endorsed by or connected with Tasmania Police, the Department of Police, Fire and Emergency Management, or the Tasmanian Government.

The purpose of publishing the aggregate results is to preserve transparent evidence of how users of the builder responded to the proposals after the consultation closed.
